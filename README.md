# Сайт топперов (студия «Разгуляев»)

- `docs/` — готовый сайт. GitHub Pages публикует именно эту папку, сборка не нужна.
- `src/` — исходники, из которых Claude собирает сайт.
  - `src/v/vD33.py` — сборщик страницы (+ `common.py`, `illus.py`, картинки, `final.html`)
  - `src/proj/` — 3D-движок `engine.js`, `catalog.json` (модели и цены), скрипты постеров и тестов
  - `src/m3/` — конвейер STL → `models/<id>.bin` (`stl_to_model.py`: сглаживание через воксели; бинарный формат, нулевое копирование в браузере)
  - `src/restore.sh` — разворачивает всё это в `/home/claude/...` в новой сессии

## Как вносить правки
Написать Claude в чате, что поменять. Он соберёт сайт, закоммитит `docs/` и `src/` — GitHub Pages обновит сайт сам (после сборки в `/home/claude/site` содержимое копируется в `docs/`).

## Порядок карточек и вкладки
Под «Каталогом» вкладки: Новый год (первая, открыта по умолчанию), Хэллоуин, Животные, Сердечки. Вкладки модели задаются полем `cats` в catalog.json (одна модель может быть в нескольких). Порядок в каталоге: сначала Новый год, потом Хэллоуин, дальше животные, сердечки; новые модели ставятся в начало своей категории. Карточка «Заказать свою модель» всегда последняя в любой вкладке; минимум для неё — 500 шт (CUSTOM_MIN в vD33.py).

## Многоцветные модели
Если модель печатается в несколько цветов (например, «Утка Санта»), в catalog.json у неё `"multi": true`: клиент не выбирает цвет, модель показывается в цветах из 3MF, минимальный тираж 500 шт (MULTI_MIN в vD33.py), цена 65 ₸/шт. Цвета вершин лежат в конце `.bin` (флаг 1 в заголовке), их собирает `src/m3/hd.py`.

## Детальные модели (с 31.10.2026)
Новые модели собираются `src/m3/hd.py`: исходная сетка из 3MF без воксельного сглаживания, упрощение до ~62 тыс. вершин (fast_simplification), подставка с плоскими гранями. Пример запуска — `src/m3/hd_newyear.py`. Многоцветные: цвета частей по филаментам из 3MF, покраска кистью (paint_color) тоже читается.

## Минимальный заказ
С 31.10.2026 минимальный заказ 100 шт (minQty в vD33.py), ступень 50+ из цен убрана. Своя модель — от 500 шт, многоцветные — от 500 шт.

## Затемнение впадин
Все модели несут цвета вершин (флаг 1): в них запечено затемнение складок и впадин (`cavity` в `src/m3/hd.py`, для старых моделей `src/m3/oldao.py`), чтобы детали читались и у одноцветных. Выбранный клиентом цвет умножается на него.
