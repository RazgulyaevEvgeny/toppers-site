# Сайт топперов (студия «Разгуляев»)

- `docs/` — готовый сайт. GitHub Pages публикует именно эту папку, сборка не нужна.
- `src/` — исходники, из которых Claude собирает сайт.
  - `src/v/vD33.py` — сборщик страницы (+ `common.py`, `illus.py`, картинки, `final.html`)
  - `src/proj/` — 3D-движок `engine.js`, `catalog.json` (модели и цены), скрипты постеров и тестов
  - `src/m3/` — конвейер STL → `models/<id>.bin` (`stl_to_model.py`: сглаживание через воксели; бинарный формат, нулевое копирование в браузере)
  - `src/restore.sh` — разворачивает всё это в `/home/claude/...` в новой сессии

## Как вносить правки
Написать Claude в чате, что поменять. Он соберёт сайт, закоммитит `docs/` и `src/` — GitHub Pages обновит сайт сам (после сборки в `/home/claude/site` содержимое копируется в `docs/`).

## Порядок карточек и вкладки
Под «Каталогом» вкладки: Хэллоуин (открыта по умолчанию), Животные, Сердечки, Новый год. Вкладки модели задаются полем `cats` в catalog.json (одна модель может быть в нескольких). Порядок в каталоге: сначала Хэллоуин, дальше животные, сердечки; новые модели ставятся в начало своей категории. Карточка «Заказать свою модель» всегда последняя в любой вкладке; минимум для неё — 100 шт (CUSTOM_MIN в vD33.py).

## Многоцветные модели
Если модель печатается в несколько цветов (например, «Утка Санта»), в catalog.json у неё `"multi": true`: клиент не выбирает цвет, модель показывается в цветах из 3MF, минимальный тираж 500 шт (MULTI_MIN в vD33.py), цена 65 ₸/шт. Цвета вершин лежат в конце `.bin` (флаг 1 в заголовке), их собирает `src/m3/multicolor_3mf.py`.
